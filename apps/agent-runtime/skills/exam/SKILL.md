# ข้อสอบ (crudex)

กติกาการเขียนข้อ ตัวลวง และฟิลด์ต่อข้อ (`topic`, `indicator`, `verify`) ใช้แบบเดียวกับใบงาน (รวมรายการหัวข้อมาตรฐานของ ป.5 เศษส่วน) ข้อต่างอยู่ด้านล่าง ข้อมูลนักเรียนเป็นข้อมูลตัวอย่างเสมอ

## ต่างจากใบงาน
- ค่าเริ่มต้น 20 ข้อ ปรนัย 4 ตัวเลือก ข้อละ 1 คะแนน ไม่มีคำใบ้ในโจทย์
- ถามครูได้ 1 คำถามถ้าขาดข้อมูลสำคัญ: ชั้น หัวข้อหรือหน่วย เวลาสอบ ถ้าไม่บอกเวลา ใช้ 1 นาทีต่อข้อ
- ส่วนหัว: ชื่อวิชา ชั้น เวลา คะแนนเต็ม คำชี้แจง 2–3 บรรทัด ช่องชื่อ เลขที่ ห้อง

## ตารางวิเคราะห์ข้อสอบ (ต้องทำก่อนออกข้อ)
1. เรียก `curriculum_lookup` เอาตัวชี้วัดของหน่วยนั้น ใช้เฉพาะรหัสที่ tool คืน
2. แบ่งจำนวนข้อตามน้ำหนักของตัวชี้วัด ทุกตัวชี้วัดที่ครูเลือกต้องมีอย่างน้อย 2 ข้อ
3. ระดับการคิดต่อชุด ประมาณ จำ/เข้าใจ 30% · นำไปใช้ 50% · วิเคราะห์ขึ้นไป 20%
4. แสดงตารางให้ครูดูในคำตอบ: ตัวชี้วัด | หัวข้อย่อย | จำนวนข้อ | ระดับการคิด | ข้อที่

## ข้อสอบเก่า (O-NET และอื่น ๆ)
- `old_exam_search` ใช้ดูรูปแบบและระดับความยากเท่านั้น ห้ามคัดลอกโจทย์ทั้งข้อ ให้เปลี่ยนตัวเลข บริบท และตัวเลือก
- ถ้าอ้างว่าเป็นแนว O-NET ให้บอกปีและแหล่งที่ tool คืน ถ้า tool ไม่คืนแหล่ง ห้ามอ้าง

## ตรวจก่อนส่ง
- เรียก `check_assessment` ทั้งชุด ถ้าไม่ผ่านแก้ตาม error ได้ไม่เกิน 3 รอบ ถ้ายังไม่ผ่านให้บอกครูว่าข้อไหนติด ห้ามบันทึก
- จำนวนข้อในตารางวิเคราะห์ต้องเท่ากับจำนวนข้อจริง

## ตอบครู
ส่วนหัว · ตารางวิเคราะห์ · ผลตรวจ · ลิงก์จาก `save_assessment` หรือ `make_file` · โจทย์และเฉลยทุกข้อ · เฉลยแยกท้ายชุดพร้อมเหตุผลสั้น ๆ ข้อละ 1 บรรทัด
