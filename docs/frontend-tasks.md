## ขอบเขตรอบ UI

ทุกฟีเจอร์ใช้ mock data ใน frontend รวมถึงฟอร์ม คะแนน การส่งรายงาน และบทบาท ทดสอบ flow และ action บน local ได้ก่อน backend พร้อม งานเชื่อม API, Google Form จริง, สิทธิ์บัญชี และการส่งจริงแยกเป็นรอบ integration ภายหลัง เมื่อจบแต่ละ task ให้ตรวจและ push เฉพาะ frontend และ tracker ไปที่ frontend/mock-ui

## รันทดสอบ

จาก root ใช้ Node 22 และ pnpm 10.34.6 แล้วรัน `pnpm --filter web dev` เปิด http://localhost:5173/ เริ่มจาก Landing ที่ / แล้วเปิด /sign-in เลือกบัญชีครูหรือ ผอ. ในแท็บเดิม ฟอร์มนักเรียน /student/5-2 เปิดจากลิงก์สาธารณะได้ ทุกหน้าในเดโมใช้ได้โดยไม่ต้องเปิด Docker หรือใส่ secret เริ่มจากแท็บใหม่ที่เปิด URL โดยตรงเพื่อลองร่างว่าง ข้อมูลร่างใช้ sessionStorage ของแท็บนั้น ส่วน /notes ทดลองเพิ่มและลบบันทึกในหน่วยความจำ

ก่อนส่งแต่ละงาน ตรวจ format, lint, typecheck และ build ทดสอบหน้าที่เปลี่ยนบนมือถือและเดสก์ท็อป เพิ่ม automated test เมื่อมีตรรกะเสี่ยงผิดซ้ำ เช่น การผูกผลงานกับห้องต้นทางหรือการเลือกผู้รับรายงาน

รอบหน้าครู Paper 01 ตรวจบนจอจำลอง 375 px แล้ว ปุ่มใช้คำสั่งตัวอย่างและทางลัดกลับช่องร่าง พาโฟกัสไปช่องร่าง ข้อความตอบกลับกับการ์ดอยู่เฉพาะห้องที่สร้าง และหน้าไม่ล้นแนวนอน Design ทวนมาสคอต ข้อความส่งมอบ และทางกลับช่องร่างแล้ว QA ทวนการแยกห้องและโฟกัสที่ 375/768/1280 px ทั้งธีมสว่างและมืด การตรวจการพิมพ์ก่อนหน้านี้ยืนยันเฉพาะรูปแบบ A4 ในโหมดจำลอง ยังไม่ได้ยืนยันจำนวนหน้าจากหน้าต่างพิมพ์จริง

QA-01 หลังแก้สถานะฟอร์ม ตรวจบน local โดยเปิดใบงานค้างแล้วจำลองฟอร์มล้มเหลว ข้อความแชต การ์ดฟอร์ม และสถานะรายห้องตรงกัน โฟกัสไปปุ่มลองใหม่ สลับห้องและโหลดหน้าใหม่แล้วยังเก็บสถานะเฉพาะห้องเดิม เมื่อลองใหม่ ใบงานยังเปิดอยู่และโฟกัสกลับไปที่ลิงก์ฟอร์ม

QA-03 รุ่น `df92108` ที่ 390 px ทดสอบตั้งแต่เลือกห้องและแก้ร่าง ส่งฟอร์มจำลอง 10 ข้อ เปิดสมุดคะแนน ตรวจร่างรายงานรายคน จนถึงสรุป ผอ. ที่ 1280 px ใช้คีย์บอร์ดเข้าถึงปุ่มหลักและส่งฟอร์มได้ รุ่น `5edbb7f` เปลี่ยนฟอนต์และช่องเลือกหลังการทดสอบนี้

รอบส่งมอบ UI `5edbb7f` บนสาขา `frontend/mock-ui` ตรวจ lint, typecheck และ build ผ่าน ทวนบนจอ 1440 px โดยสร้างชุด ป.5/2 แล้วสลับไป ป.5/1 พบช่องร่างว่าง กลับห้องเดิมเปิดฟอร์มที่ /student/5-2 ได้ จากสมุดคะแนนเปิดร่างรายงานของบ้าน 4 ได้ 4/10 เมื่อเปลี่ยนเป็นบ้าน 1 ร่างเก่าปิดและต้องเปิดตรวจใหม่ จึงเห็นปลายทางบ้าน 1 กับคะแนน 10/10 ส่วนห้องว่าง ป.6/1 ไม่มีรายชื่อค้าง

ผลทวน UI รุ่นเดียวกับ `5edbb7f` หลังเปลี่ยนฟอนต์

- Design ตรวจหน้าครู สมุดคะแนน และรายงานที่ 375 และ 1280 px สลับธีมสว่างและมืด ฟอนต์ Noto Sans Thai โหลดทั้งไทยและละติน ลูกศรไม่ทับชื่อห้องหรือชื่อผู้รับตัวอย่าง
- QA ทวนที่ 390 px ส่งฟอร์ม ป.5/2 ด้วยชื่อสมมติได้ 10/10 และร่างรายงานเปลี่ยนจากบ้าน 4 (4/10) เป็นบ้าน 2 (9/10) ตรงคน การทดสอบมือถือใช้จอจำลอง
- FE-02 บน `d46c668` ในโหมดพิมพ์จำลอง ใบงาน ป.5/2 มีโจทย์ครบ 10 ข้อ สองคอลัมน์ ขอบ 15 มม. เฉลยและปุ่มพิมพ์ถูกซ่อนแม้เปิดเฉลยค้าง เมื่อกดพิมพ์ในเบราว์เซอร์ทดสอบ แท็บหมดเวลารอและไม่มีตัวอย่างหรือ PDF ให้ตรวจ จึงยังไม่ยืนยันจำนวนหน้าหรือรอยตัดจริง

## เส้นเดโม Landing และแชตต่อเนื่อง

- เปิด / → เข้าสู่ระบบด้วยบัญชีเดโม → เลือกครู → พิมพ์ “ทำใบงานเศษส่วน” และกด Enter ดูใบงาน A4 ฟอร์มนักเรียน และควิซที่ครูเปิดทีละข้อบนเครื่องเดียวกัน
- ถาม “อธิบายข้อ 3” แล้วถาม “ข้อต่อไปล่ะ” เพื่อทวนข้อ 4 ของชุดเดิม หรือถาม “ใครต้องติว” แล้วเปิดสมุดคะแนนของห้องจากคำตอบ บทสนทนาเก็บแยกห้องในแท็บปัจจุบัน แชตตอบตามตัวอย่างและข้อมูลห้อง
- ออกจากระบบ แล้วเปิด /teacher หรือ /principal โดยตรง ระบบพาไป /sign-in บัญชีตัวอย่างและการกั้นหน้าทำในเบราว์เซอร์ งานยืนยันสิทธิ์ที่ API ยังอยู่ใน QA-04

### School API รุ่นทดสอบในเครื่อง

- รุ่น UX `c3a71ba` ผ่านการเลื่อนเฉพาะประวัติที่ 390×844 และ 1280×900 เมื่ออ่านย้อนหลังแล้วคำตอบเข้ามา ตำแหน่งอ่านคงเดิม เมื่ออยู่ท้ายแชต หน้าตามคำตอบใหม่ได้
- ในหน้าแรกเลือก **พื้นที่โรงเรียน** (`/school`) → เข้าพื้นที่ครู → พิมพ์คำขอในห้องที่เซิร์ฟเวอร์อนุญาต → เปิดใบงาน → เปิดฟอร์มนักเรียน ครูดูตัวอย่างได้ นักเรียนที่ได้รับมอบหมายให้ห้องนั้นส่งคำตอบผ่าน `/play/$token` ได้ สำหรับทดสอบในเครื่องเดียว ให้ออกจากบัญชีครูในหน้าฟอร์มแล้วเลือกบัญชีนักเรียนตัวอย่าง
- ทดสอบผ่านหน้าเว็บกับ API จาก main `8e87de4` และ PostgreSQL ในเครื่อง ครู ป.4/1 ส่งคำขอ บริการคิวบันทึกใบงาน นักเรียนตอบ 1/2 ได้ 1/1 เมื่อกลับเข้าบัญชีครู สมุดคะแนนแสดง 1/1 บัญชี ผอ. เห็นยอดส่ง 1 และค่าเฉลี่ย 100% ของวันทดสอบ
- ชุดทดสอบใช้ Worker ตัวอย่างใน `apps/api/scripts/fixtures` ทำหน้าที่ผู้ช่วยและส่งโจทย์เศษส่วนคงที่ ตั้ง `VITE_SCHOOL_GATEWAY_FIXTURE=true` ในสภาพแวดล้อม Vite เมื่อใช้ชุดนี้เพื่อให้หน้าเว็บระบุที่มาของใบงาน ขั้นตอนเปิดบริการอยู่ใน [คู่มือ local](https://chokchai-fa.github.io/crudex/getting-started/local-development) บัญชี สิทธิ์ งาน ใบงาน คำตอบ และคะแนนในเส้นนี้ใช้ School API ส่วนแชตสาธิตที่ `/teacher` ควิซสด Google Forms และการส่งรายงานผู้ปกครองยังใช้ตัวอย่าง

### สถานะในแชตครู

หน้า `/teacher` แสดงคำขอของครูและสถานะจำลองในรายการเดียวกัน เมื่อคำตอบพร้อมจะแทนที่สถานะที่ตำแหน่งเดิม เปิดรายละเอียดเหตุการณ์ที่บันทึกไว้ของคำขอใหม่ได้ การลองฟอร์มใหม่ยังคงใบงานที่ครูเปิดไว้ ทวนบนจอจำลอง 390×844 และ 1280×900 แล้ว ทั้งหน้าอยู่กับที่ โฟกัสกลับช่องพิมพ์หลังส่งข้อความ และการอ่านย้อนหลังคงตำแหน่งเดิม เปิด reduced motion แล้วข้อความยังขึ้นครบโดยไม่มีแอนิเมชัน

หน้าแชตจัดห้องและผู้ช่วยไว้ซ้าย ผลงานสามแบบอยู่ในบทสนทนา ส่วนสถานะควิซทางขวาตามข้อที่ครูเปิดจริง มือถือพับเมนูห้องและแสดงบัญชีตัวอย่างที่หัวแชต วัดแถบพิมพ์รวมคำสั่งลัดบนจอ 1440×900 ได้ 106 px (เดิม 145) และ 390×844 ได้ 100 px (เดิม 137) ตัวแคปซูลเริ่มที่ 50 px ทั้งสองขนาด กด Enter เพื่อส่ง หรือ Shift+Enter เพื่อขึ้นบรรทัดใหม่

รุ่น `a55b8e8` เรียงการ์ดผลงานเป็นสามแถวที่ 390 px แต่ละใบกว้าง 370 px ปุ่มสูง 44 px ขึ้นไป เดสก์ท็อปยังแสดงสามใบในแถวเดียว ที่ `/school` ครูเปิดรายละเอียดงานเพื่อดูข้อความและเหตุการณ์จาก `GET /api/runs/:id/events` ทั้งงานที่เพิ่งส่งและงานในประวัติ ทดสอบห้อง ป.4/1 ในเครื่องผ่านตั้งแต่รอคิวจนบันทึกใบงาน ส่วนเนื้อหาใบงานมาจากผู้ช่วยจำลองในเครื่อง

### เส้นทดสอบ School API ในแชตครู

เปิด `/school` เข้าบัญชีครู เลือกห้องแล้วกด **เปิดแชตเลขาครู** หน้า `/teacher` ตรวจบัญชีและห้องผ่าน School API แสดงประวัติตามห้อง ส่งคำขอและอ่านเหตุการณ์จาก run ID เปิดใบงานและฟอร์มนักเรียนจาก ID ที่ API คืน สมุดคะแนนอ่านจากฐานข้อมูลโรงเรียน นักเรียนเข้าจากลิงก์ฟอร์มด้วยบัญชีที่ได้รับมอบหมาย

การทดสอบ live ต้องให้ Worker ส่งงานไป gateway และ runtime ที่มีสิทธิ์ใช้โมเดล พร้อม callback กลับ School API ได้ เมื่อยืนยัน binding แล้วจึงตั้ง `VITE_SCHOOL_GATEWAY_FIXTURE=false` สำหรับ Vite ในเครื่อง การเปลี่ยน flag อย่างเดียวไม่เปลี่ยน gateway ชุดทดสอบที่ใช้ fixture ปิดปุ่มส่งแชต รุ่นนี้ยังไม่มีหลักฐาน live run, การถามต่อ, การส่งคำตอบจากใบงานของ live run หรือคะแนนของใบงานนั้นหลัง reload
