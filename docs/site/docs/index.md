Crudex helps Thai school staff create verified worksheets, grade quizzes, prepare family reports and review budget claims. A school account determines which records and assistants each person can use.

## Start here

- [School workflows](product/workflows.md) follows a worksheet from a teacher’s prompt to a student’s score.
- [Run Crudex locally](getting-started/local-development.md) sets up a disposable development environment and verifies a school workflow.
- [Integrate the school API](integrations/school-api.md) covers sign-in, streaming a run, resuming after a disconnect and reading results. Browse or download the [OpenAPI contract](reference/openapi.mdx) for request and response schemas.
- [Agent run lifecycle](architecture/run-lifecycle.md) explains how the API, queue and sandbox handle a request. The [database reference](reference/database.md) describes the records that survive a sandbox restart.

The [demo gateway](integrations/demo-gateway.md) lets you try the agents with sample data and a passcode.
